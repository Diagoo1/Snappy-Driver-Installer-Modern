# إضافات الواجهة الحديثة

## الحالة وأولوية المطابقة

شارة التعريف تعرض حالة مختصرة: Installed أو Missing أو Upgrade أو Downgrade، وتترجم حسب لغة الواجهة. لا تظهر بادئة SDIO. الحالة مبنية على وجود التعريف الحالي وأعلام الإصدار المختار في المحرك. البديل غير المؤهل يظهر Invalid، والجهاز المتجاهل يظهر Ignored.

النجوم الخمس تعبر عن أولوية المطابقة النسبية من ترتيب المحرك بين البدائل الصالحة للجهاز؛ ليست تقييم أمان. لا تغيّر ترتيب المحرك أو صلاحية التثبيت.

## الثيمات

من الإعدادات يمكن استيراد ملف `.sdi-theme.json`، معاينته ثم تطبيقه أو إلغاؤه، وتصدير الثيم الحالي. عينة `themes/copper-night.sdi-theme.json` نقطة بداية قابلة للتعديل. الملف بيانات ألوان فقط؛ لا يحتوي سكربتات أو CSS. راجع `themes/README_AR.txt` للمفاتيح والحدود وقواعد التباين. اختيار الثيم محفوظ في حساب ويندوز، بدون ملف إعدادات بجوار EXE.

## مشاركة التنزيلات

مركز التنزيل ← إعدادات النقل ← استمرار مشاركة التنزيلات الموثوقة. المشاركة تستمر بعد اكتمال التنزيل وأثناء فتح البرنامج، ويُستأنف تحميل الأجزاء المحفوظة للمشاركة عند تشغيله لاحقًا إذا ظل الخيار مفعّلًا. إلغاء الخيار يوقف جلسات المشاركة. إغلاق البرنامج يوقفها كذلك؛ لا تُثبت خدمة خلفية.

تُشارك فقط أجزاء كاملة تم التحقق من SHA-1 الخاص بها وفق بيانات التورنت. تظل أولوية تنزيل أجزاء المشاركة صفرًا، فلا تُنزّل حزم غير مطلوبة. تُحفظ بيانات المشاركة في `.sdio-downloads` داخل مجلد التعريفات، ويستهلك الاحتفاظ بالأجزاء مساحة إضافية. حدود الرفع والاتصالات مشتركة بين جلسات المشاركة. إيقاف المشاركة يحتفظ بذاكرة الأجزاء لتسهيل الاستئناف.

## إعادة التشغيل

خيار «إعادة التشغيل تلقائيًا عند الحاجة» ضمن خيارات التثبيت. عند اختياره، وبعد انتهاء قائمة تثبيت ناجحة تحتاج لإعادة التشغيل، يظهر عد تنازلي 60 ثانية مع «لاحقًا» و«الآن». لا تُفرض إعادة التشغيل على التطبيقات المفتوحة. التثبيت الملغى أو الفاشل لا يبدأ العد التلقائي. المحاكاة والتحقق من خطط JSON لا يعيدان تشغيل ويندوز.

## تحديث البرنامج

الإعدادات ← تحديث البرنامج ← مستودع GitHub بصيغة `owner/repository`. المستودع الافتراضي للمشروع هو `Diagoo1/Snappy-Driver-Installer-Modern`، وتستخدم القناة إصداراته العامة المستقرة.

ملف الإصدار المطلوب اسمه `SnappyDriverInstaller-TS.exe`، ورقم الوسم مثل `v0.19.0`. تُرفض الإصدارات التجريبية والمسودات، والملفات دون بصمة `sha256:` التي يوفرها GitHub. تُفحص البصمة والحجم وملف PE قبل طلب إعادة تشغيل التطبيق للاستبدال. التنزيل عبر HTTPS، دون تجاوز التحقق من الشهادة. دعم اتصال GitHub على ويندوز القديم يعتمد على دعم TLS في النظام؛ يبقى التحديث اليدوي بنسخ EXE متاحًا.

التطبيق يستخدم نسخة مؤقتة من ملفه كمساعد للاستبدال بعد خروج النسخة الحالية، ولا يحتاج DLL أو PowerShell. يُكتب الملف بصورة ذرية، وتُرفض الوجهة غير القابلة للكتابة قبل إغلاق الواجهة. قد تبقى نسخة المساعد داخل مجلد Windows المؤقت `sdi-update-*`؛ لا توجد ملفات تشغيل إضافية مطلوبة للتوزيع.

## اللغات والأتمتة

الكتالوج المدمج يتيح 40 لغة دون مجلد لغات خارجي، مع RTL للعربية والفارسية. أُزيلت العبرية من موارد التطبيق والقائمة، ويُرحّل اختيارها القديم إلى الإنجليزية. العربي مكتمل للنصوص المجمعة حاليًا. الترجمة المجتمعية الأخرى تضم نصوصًا مولّدة آليًا تحتاج مراجعة لغوية، وتغطية عبارات الواجهة المجمّعة مكتملة في اللغات الأربعين. الأعداد والنصوص الناقصة موثقة في `docs/LOCALIZATION_COVERAGE.json`؛ اكتمال قائمة اللغات لا يعني اكتمال مراجعتها أو كل ترجمتها.

خطط JSON الحالية تغطي اختيار التعريفات والتحقق منها ثم تنفيذها بموافقة صريحة. أُضيف مفسّر للسكربتات القديمة مع التحقق من الملف قبل التنفيذ. راجع `docs/LEGACY_COMPATIBILITY_AR.md` للصيغ والفروق المقصودة وحدود الاختبار.

## حدود الاختبار

اختبارات الواجهة والملفات والشبكة المحلية لا تثبت نجاح التثبيت الحقيقي أو الاستعادة أو إعادة التشغيل على كل إصدارات ويندوز. لم يُنفذ تثبيت تعريف أو إعادة تشغيل فعلي على الجهاز الرئيسي، ولا تتوفر بيئة XP أو آلة افتراضية للتحقق النهائي.
