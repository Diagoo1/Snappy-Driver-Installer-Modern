# القوائم وحركة النافذة ومعرض الصور — 0.21.3

أزيلت طبقة اللقطة المتحركة التي كانت تخفي النافذة وتكبّر صورةً بديلة. التصغير والتكبير والاستعادة تمر الآن بإدارة النوافذ في النظام، دون التقاط صورة أو تغيير الشفافية أو تحريك هندسة نافذة إضافية في كل إطار. شكل حركة Windows نفسها يتبع نظام التشغيل وإعداداته. أنيميشن الواجهة والقلب والقوائم ما زال موجودًا.

تغيير حالة النافذة لا يعيد تطبيق ستايل البرنامج كاملًا. تحديث الحواف يقتصر على صفحات المحتوى عندما يتغير وضع التكبير، ولا يعاد عند التصغير فقط.

قوائم النصوص القابلة للتحديد والحقول والتحرير تستخدم إطار المشروع الدائري، وألوان الفاتح والداكن، مع مساحة مستقلة للاختصارات. تبقى وظائف التحرير الأصلية متصلة بأفعال Qt، وتشمل القوائم نسخ النص وتحديد الكل. صححت أيضًا نصوصًا عربية في محاكاة التثبيت وعرض الشارة وعناوين جدولها.

المعرض في `docs/GALLERY.md` يحتوي 68 صورة، أربع مجموعات عربية/إنجليزية وفاتحة/داكنة. الأجهزة المعروضة بيانات عامة؛ لقطات التثبيت واكتماله من وضع المحاكاة الصريح. لا تحتوي الصور المنشورة أسماء جهاز شخصية أو معرّفات مثيل حقيقية أو مسارات المستخدم.
