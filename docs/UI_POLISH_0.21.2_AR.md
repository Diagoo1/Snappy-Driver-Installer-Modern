# تحسينات تبويب الجهاز والحركة — 0.21.2

تبويب «الجهاز» داخل مقارنة التعريفات أصبح ثلاث بطاقات: معرّف مثيل الجهاز، معرّف العتاد وحالة Windows PnP. تستخدم نفس أسلوب المقارنة بألوان الأزرق والبنفسجي والتركواز، مع الحفاظ على قيم المعرّفات قابلة للتحديد والنسخ واتجاهها التقني.

التوقيع أصبح «صُنع بكل ❤️ بواسطة» والاسم تحته. القلب مرسوم كمسار متجهي بتدرج وردي، وله نبضة رئيسية ثم ثانية أخف، وراحة قبل تكرار الدورة. التوقيت بالزمن المنقضي، ويتوقف المؤقت أثناء إخفاء البطاقة وينام خلال الراحة، ويحترم تقليل الحركة.

التصغير والتكبير والاستعادة تستخدم لقطة برمجية لا تتجاوز 960×640 بكسل، مع مدة مستهدفة 165 مللي ثانية وخمس خطوات تحريك كحد أقصى. تُحرّك اللقطة بدل إعادة ترتيب الواجهة عند كل إطار. لا توجد مكتبة GPU إضافية؛ عند فشل تخصيص اللقطة أو تفعيل تقليل الحركة ينتقل البرنامج مباشرةً لحالة النافذة المطلوبة. تُمنع الإجراءات المتكررة أثناء الانتقال وتُحرَّر اللقطة في نهايته.

اختبارات الواجهة تغطي تعظيم النافذة واستعادتها وتصغيرها واستعادتها بعد التصغير، والضغط المكرر، وحدود اللقطة والإطارات، واختفاء نافذة التحريك وعودة الشفافية للحالة الطبيعية. اجتيازها على جهاز التطوير لا يعد قياس أداء على جهاز يستخدم Microsoft Basic Display؛ هذا السيناريو يحتاج اختبارًا فعليًا قبل ضمان معدل إطارات معين.
