# تحسينات الواجهة — 0.21.1

- قائمة التكبير تستخدم ستايل القوائم المشتركة بدل مظهر Windows الافتراضي. إطار القائمة يتبع وضع البرنامج الفعلي، والهوفر والاختيار بألوان مناسبة للوضع الداكن والفاتح والثيم المستورد.
- تعطيل نسب التكبير غير المناسبة للشاشة ينتقل إلى القائمة المنبثقة؛ لا تتحول الخيارات المعطلة في الموديل إلى خيارات قابلة للاختيار. أزيل البحث غير الضروري من قائمة النسب القصيرة.
- بطاقة المطوّر بتدرج كحلي/تركواز وحدود دقيقة وهالة وإطار ذهبي/تركواز للصورة، مع إبراز الاسم ونصوص واضحة في الوضعين. الرسوم مرسومة مباشرةً بلا صور كبيرة إضافية.
- المقارنة تفصل التعريف المثبّت بالأزرق والمرشح الموصى به بالتركواز والبديل بالذهبي. الإصدار أبرز، والبطاقات متوازنة الارتفاع، والتبويبات أوضح والخلفية غير مملوءة بلوح مسطح ضخم.
- النجوم في المقارنة تستخدم أولوية المرشح المختار نفسها. الإصدارات والقيم التقنية تحتفظ باتجاهها LTR داخل الواجهة العربية.

التغيير يخص العرض والقائمة المشتركة؛ ترتيب المحرك وهويات المرشحين ومسار التثبيت لم تتغير. المحرك المثبت وقيود اختباره موثقة في مقارنة المصدر. الفحص عند 100% و150% يشمل العربية والإنجليزية والفاتح والداكن.
