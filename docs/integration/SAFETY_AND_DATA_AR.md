# حدود السلامة والبيانات

البرنامج التجريبي ليس أداة للاستعمال الإنتاجي بعد. امتلاك صلاحيات Administrator لا يعني أن التعريف المقترح آمن أو مناسب دون مراجعة.

- استعمل حزمًا وفهارس موثوقة. لا تُثبت تعريفات عشوائية أو مجهولة المصدر.
- الدرجة الخام من Matcher تعبر عن المطابقة، وليست تقييمًا أمنيًا أو شهادة جودة.
- إنشاء Restore Point ليس ضمانًا لاستعادة جهاز معطل، وقد يكون غير متاح. احتفظ بنسخة رجوع مستقلة.
- السكربت يزيل من النسخة المعدلة تشغيل عامل الضغط التلقائي على نوافذ موافقات Windows ويحافظ على سجل SetupAPI.
- يُمنع التثبيت الواسع إذا كان Hardware ID مشتركًا بين أجهزة متعددة. وقد يمنع ذلك بعض الأجهزة الصحيحة مؤقتًا؛ هذا أفضل من تغيير جهاز غير مختار.
- يتم فحص الحزمة وتثبيت قفل قراءة أثناء استخدامها. هذا ليس توقيعًا رقميًا للحزمة ولا بديلًا عن التحقق من مصدرها.
- لا يوجد قتل قسري للتثبيت، ولا إعادة تشغيل Windows تلقائيًا.
- السجلات محلية ولا يتم إرسال Telemetry. قد تحتوي على معرّفات أجهزة أو مسارات شخصية؛ راجعها قبل مشاركتها.
- لا يُطلب تعطيل Defender أو مضاد الفيروسات أو فحص توقيع التعريفات.
- لا يُنزَّل أو يُشغَّل أي EXE من حزمة مرجع التصميم القديمة.

مخطط العمل: Scan → immutable snapshot → explicit selection → generation/identity/file validation → explicit consent → original installer → actual results → mandatory rescan.

الفحص الأصلي قد يكتب ملفات فهرسة وكاش حتى في هدف matching-only. «لا يثبت تعريفات» لا تعني «لا يكتب أي ملف».
