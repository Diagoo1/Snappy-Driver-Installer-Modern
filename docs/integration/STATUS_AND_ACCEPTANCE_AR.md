# حالة الدمج ومعايير القبول

## الفرق عن النسخة السابقة

النسخة السابقة تشغّل SDIO كعملية مستقلة لتصدير بيانات التعريف المثبت، ولا تحصل على البدائل.
هذه الحزمة تحتوي كود Adapter يتعامل مباشرة مع `Matcher` و`Manager` و`State` و`Installer` داخل مكتبة C++ مرتبطة بالتطبيق. كتابة الربط تمت؛ نجاح Build واختبار Windows لم يتم إثباتهما.

## بوابات الاعتماد — لا يجوز تجاوزها

### 1. نجاح البناء
يبنى التطبيق باستخدام Qt/MinGW المطلوبين. لا أخطاء ربط ولا ملفات DLL مفقودة.
تحقق من أن BUILD_MANIFEST يذكر `nativeLinked=true`.
ظهور الواجهة أو نجاح اختبارات النصوص لا يكفي.

### 2. تكافؤ المطابقة
قارن نسخة SDIO المطابقة لنفس baseline مع نسختنا، باستخدام نفس الحزم والفهارس ونفس الجهاز.
قارن Hardware IDs وCompatible IDs وINF وSection والإصدار والتاريخ وترتيب المرشحين والدرجة الخام.
لا تقارن ترتيبنا بإصدار أصلي مختلف ثم تعتبر الاختلاف خطأ تصميم.
قاعدة إبراز «الموصى به» في الواجهة تستخدم أعلام المحرك، لكنها تحتاج أيضًا مقارنة اختيار SDIO الافتراضي عمليًا.

### 3. التثبيت
على جهاز اختبار فقط، اختبر جهازًا واحدًا محلي الحزمة: نجاح، فشل، حزمة مفقودة، تغير الحزمة بعد الفحص، جهاز مفصول، رفض UAC، فشل إنشاء نقطة استعادة، والحاجة لإعادة تشغيل.
تحقق من إصدار التعريف بعد الفحص التالي ومن سجل SetupAPI.
التثبيت يعمل على Hardware ID؛ لهذا تمنع الحزمة اختيار ID مشترك بين عدة أجهزة، بدل تغيير أجهزة لم يحددها المستخدم.

### 4. الاستمرارية والإلغاء
اختبر أكثر من فحص وتثبيت متتاليين، ثم الإيقاف والغلق في المراحل المختلفة.
لا تُقتل عملية Windows الجارية، ولا تستعمل Thread::terminate.
إذا أغلق Windows نفسه أو انقطع التيار فلا توجد ضمانة من واجهة البرنامج.

### 5. التوزيع والتوافق
اختبر الملف على أنظمة نظيفة لا تحتوي أدوات التطوير.
اختبر XP SP3 x86 وWindows 7/10/11 بحسب النطاق المستهدف.
اختبر غياب تعريف GPU، واللغة العربية، وDPI، والذاكرة مع فهارس كبيرة.
مساعد x64 المبني بـ MSVC حديث غير معتمد على XP x64.
إصدار Qt قديم وغير مدعوم حاليًا؛ لا يُعلن أنه خالٍ من الثغرات.

## الفرق بين عدد الاختبارات ونضج المنتج

58 تحققًا تنفيذيًا هنا تخص مكوّنين مستقلين: سياسة الاختيار والـ backend غير المتوفر.
26 مراجعة بنيوية تفحص توصيل السورس فقط.
لا يوجد اختبار تطابق Matcher ناجح، ولا تثبيت Windows ناجح، ولا قياس أداء أو حجم EXE نهائي في هذه الحزمة.

المطلوب النهائي «برنامج كامل جاهز» **لم يتحقق بعد**. هذه الحزمة تقدم عمل الدمج المكتوب وأدوات التحقق والبناء، ولا تستبدل اختبار Windows.
