# مثبّت التعريفات — الواجهة الحديثة

**نسخة بيتا للتجربة:** [الإصدار 0.21.4 Beta](https://github.com/Diagoo1/Snappy-Driver-Installer-Modern/releases/tag/v0.21.4). اختبار التوافق مع الأجهزة وإصدارات ويندوز ومعماريات المعالج مستمر؛ التحديث التلقائي يتابع القناة المستقرة.

زر **الإبلاغ عن مشكلة** موجود في «حول البرنامج» و«الأدوات». يعرض معاينة للإصدار والنظام والمعمارية واللغة والثيم قبل فتح نموذج GitHub العلني، ولا يرسل بلاغًا تلقائيًا أو يرفق معرّفات الأجهزة والسجلات. راجع أي مرفقات قبل نشرها. [فتح نموذج البلاغ](https://github.com/Diagoo1/Snappy-Driver-Installer-Modern/issues/new?template=bug_report.yml).

واجهة Windows من تطوير **طارق صادق — Diagoo1**، مبنية بلغة C++ وQt على محرك SDIO مثبّت المصدر. الملف التنفيذي يدمج المحرك والخطوط والترجمات والمكتبات؛ التعريفات والفهارس منفصلة. [الإصدارات](https://github.com/Diagoo1/Snappy-Driver-Installer-Modern/releases).

الإصدار **0.21.4 Beta** يشمل الفحص والمطابقة الأصلية والإصدارات البديلة والتثبيت والاستخراج والتنزيل والاستئناف والمشاركة أثناء تشغيل البرنامج، والسكربتات القديمة وخطط JSON وصيانة الفهارس والسحب والإفلات والتكبير المستقل والثيمات الحديثة. الإعدادات في Registry للمستخدم دون ملف كونفج أو DLL بجوار البرنامج.

العربية RTL بخط Cairo المدمج، والإنجليزية Satoshi. توجد 40 لغة؛ العربية والإنجليزية تغطيان النصوص الحالية. هناك 11 نصًا جديدًا للبلاغ والبيتا تظهر بالإنجليزية مؤقتًا في باقي اللغات، مع حاجة الترجمات الآلية للمراجعة. النجوم أولوية مطابقة نسبية وليست تقييم أمان.

ضع `drivers` و`indexes` بجوار EXE أو اختر مساراتهما. السحب يقبل مجلد تعريفات أو لقطة `.snp` ولا ينفّذ ملفات برامج أو سكربتات. التكبير من الإعدادات يحتاج إعادة تشغيل ويُقيّد بمساحة الشاشة. التحديث من إصدارات مستودع المشروع بفحص الحجم وSHA-256 وصيغة الملف؛ الإصدار غير موقّع بشهادة رقمية.

**حدود التحقق:** الفحص والمطابقة واللقطات والاستخراج اختُبرت على جهاز التطوير. تثبيت تعريفات حقيقية ونقطة الاستعادة وإعادة تشغيل Windows وتشغيل EXE على XP وباقي الأنظمة القديمة تحتاج جهاز تجارب. بناء x86 وتدقيق الاستيرادات لا يثبتان وحدهما التوافق الكامل.

للبناء راجع [README](README.md) و[دليل البناء](docs/BUILDING.md). شغّل `python tools/integration/bootstrap_fonts.py` أولًا لتنزيل Satoshi الرسمي والتحقق منه؛ ملفاته المستقلة لا تُوزّع في المستودع.
